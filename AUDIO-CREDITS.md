# Squakle audio sources

24 playable species. Each clip has its own attribution and license; adaptations retain that license.

Screening: source descriptions reviewed, then BirdNET 2.4 applied to 3-second windows with 2-second overlap. Final encoded clips required target peak >= 0.70 and all other label scores < 0.10 in complete windows. Partial trailing windows are excluded because padding changes model input. Scores are screening signals, not probabilities. This is not a human listening certification or proof of a single physical bird. Ambient sound can remain.
